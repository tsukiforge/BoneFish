# BoneFish

A custom bootstrapper for Roblox on Windows, with performance tweaks, UI customization, and quality-of-life features.

> BoneFish is a fork of [Bloxstrap](https://bloxstraplabs.com). It is not affiliated with Roblox Corporation or the original projects. The only official download is the [Releases page](https://github.com/BoneFishStudio/BoneFish/releases/latest) — anywhere else offering BoneFish is not us.

## Features

**Performance**

- FastFlag presets: Auto-Optimize, Stable, Ultra Low-Spec, Extreme Performance, Balanced
- FPS Unlocker, Turbo Mode, and a Fast Loading toggle
- HDD/SSD auto-detection with presets that adapt to slow storage
- Protection against "Not Responding" freezes on low-end devices
- FPS monitor overlay (`Ctrl+Shift+F`) and crosshair overlay (`Ctrl+Shift+C`)

**Customization**

- Custom wallpapers and loading screens
- Custom fonts, cursors, and emoji styles
- Bootstrapper styles, icons, and fully custom themes
- Clean dark/light UI

**Tools**

- Server info and history with one-click rejoin
- Auto-reconnect after a crash
- Auto cache cleaner and quick shortcut repair
- Game Session Manager and multiple Roblox instances
- Roblox Studio support, channel switcher, auto-updates

## Install

1. Grab the latest release from the [Releases page](https://github.com/BoneFishStudio/BoneFish/releases/latest)
2. Extract the ZIP and run `BoneFish.exe`
3. Follow the setup wizard

Requirements: Windows 10 (1809+) or Windows 11, 64-bit, .NET 9 runtime (installed automatically if missing), around 200 MB of disk space.
